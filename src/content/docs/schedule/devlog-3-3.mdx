Through this dev-log I got to learn about API integration. API stands for application programming interface. I remember talking about them two years ago when I took Critical Web Design and hearing them and multiple points but I didn't quite remember how they worked. Now I do. I learned that essentially API's help fetch data for a dynamic website. So for instance with the Bad Password API, when we connected the API, the white page simply showed the different combination of bad passwords. It was fetching the data from the information base we had. For the last step, we connected it with the front-end so that when we pressed a button, we would see the data of the API being reflected. Lately, I've also been hearing about Vercel but I didn't understand why we were using it. After this tutorial I know the difference between hosting a static website (Github) and a dynamic website (Vercel). I was a little confused on was node and express where but now I know that Node allows JavaScript to run outside the browser. Express helps to organize how the server responds. JSON = JavaScript Object Notation and it refers to a way to package or organize objects so that they can be sent for instance between front end and back end.
