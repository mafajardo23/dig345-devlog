#### Create a database-driven application using Node/Express/MongoDB 


Use Node.js and MongoDB Atlas to create the back end for Big Feelings. Then publish your full-stack application on Vercel. Follow Modules 10.3 in Critical Web Design and [Module 10.4 on the CWD Wiki](https://criticalwebdesign.github.io/wiki/chapter-10/10-4-big-feelings/) to complete your DevLog.

1. Modify the project structure, install dependencies, and run the project.
1. Create a MongoDB Database (CWD 10.4)
1. Create an `.ENV` file, add your connection credentials, and test your database connection (CWD 10.4)
1. Add routes to get data from MongoDB (CWD 10.4)
